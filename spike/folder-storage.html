Folder storage prototype

Stores each idea as its own JSON file and each image as a real binary file in a folder you pick, instead of packing everything into one JSON document. Point it at a folder, paste some screenshots into a description, then use Compare with single file to see what the same content would cost as one document. Everything is measured on your machine with your data.
