Discovery Desk embed probe

Answers one question: can a page hosted on your own domain, embedded in a SharePoint page, sign a user in and read SharePoint lists through Microsoft Graph? Run it as a top-level page first to get a baseline, then embed the same URL in a SharePoint page and run it again. The two results together tell you whether the embedded approach is viable or whether the app has to open in its own tab.
